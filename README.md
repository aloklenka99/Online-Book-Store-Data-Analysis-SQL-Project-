📌 Project Overview

This project focuses on analyzing an Online Book Store dataset using SQL.
The goal is to extract meaningful insights related to sales, customers, books, and revenue trends.

The project demonstrates strong hands-on experience in:

* Data Cleaning
  
* Data Analysis using SQL
  
* Business Insight Generation
  
* Advanced SQL Concepts


🗂️ Dataset Information

The project uses the following datasets:

1. 📘 Books Table

2. 👤 Customers Table

3. 🛒 Orders Table


🧹 Data Cleaning & Validation

Performed the following checks:

✔️ Null value detection in all tables

✔️ Duplicate records identification

✔️ Data consistency validation


📊 Key Analysis Performed

🔹 Basic Analysis

* Retrieve books by genre (Fiction)
  
* Customers from specific countries
  
* Orders placed in a specific month
  
* Total stock available
  
🔹 Advanced SQL Analysis

📈 Sales & Performance Insights

* Total books sold per genre
  
* Monthly sales & Month-over-Month growth
  
* Yearly sales & Year-over-Year growth
  
👥 Customer Insights

* Customers with multiple orders
  
* Top spending customers
  
* Customers contributing to 80% revenue (Pareto Analysis)
  
📚 Product Insights

* Most frequently ordered book
  
* Top-selling book per genre
  
* Books never sold

✅ Joins (INNER, LEFT)
